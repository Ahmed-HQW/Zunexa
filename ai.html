تُستعمل هذه الإعدادات في الإدخال الصوتي (🎤) وفي القراءة الصوتية للردود (🔊 بجانب كل رد) — عبر Web Speech API المدمجة في المتصفح، بدون أي مفتاح API.

إشعار عند اكتمال الرد
إشعار من المتصفح عند ما يخلص Archon من رد طويل — مفيد إذا بدلت التبويب فالمتصفح.
تعلّم من المحادثات
يخلي Archon يسجل الأسئلة الجديدة اللي ما عندوش جواب عليها ويقوّي قاعدة المعرفة تلقائياً (Supabase ai_learning / ai_knowledge).
الأدوات الخارجية
تفعيل الأوامر السريعة /طقس /خريطة /جيت /اخبار /صورة والاتصال بـ APIs مجانية خارجية بدون مفتاح.

كلشي فهاد الصفحة خدام دابا بلا أي مفتاح (Pollinations، الطقس، الخرائط، GitHub، الأخبار، البحث عبر DuckDuckGo، والصوت عبر المتصفح). هاد المفاتيح اختيارية — كل وحدة عندها Free Tier فابور، تسجل فـ 2 دقيقة وتلصقها هنا باش تزيد جودة/حدود أعلى. كتبقى محفوظة فـ localStorage ديال المتصفح ديالك فقط، ما كتترسلش لأي سيرفر آخر غير مباشرة للـ API ديالها.

روابط التسجيل الفابور: huggingface.co/settings/tokens · deepl.com/pro-api · voicerss.org · tavily.com · serper.dev
